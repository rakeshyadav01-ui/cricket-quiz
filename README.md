# 🏏 Cricket Quiz

A simple and interactive Cricket Quiz application built using:

- HTML
- CSS
- JavaScript

## Features

- 20 questions stored in a JavaScript question bank
- 5 questions selected randomly for every quiz
- 4 options for every question
- Radio button based answers
- Dynamic question generation
- Score calculation
- Progress indicator
- Result screen
- Restart / Try Again functionality
- Responsive design for mobile and desktop
- Attractive modern UI
